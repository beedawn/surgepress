# SurgePress

SurgePress is a lightweight static site generator written in Go. It converts a directory of Markdown files into static HTML pages, builds an index page, and generates an RSS feed using site metadata from a JSON configuration file.

## Features

- Markdown-to-HTML rendering with `goldmark`
- Front matter / metadata support
- HTML template rendering
- Per-page and global stylesheet support
- Generated index page
- RSS feed generation
- Simple command-line interface
- Modular internal packages with unit tests

## Requirements

- Go 1.24 or later

## Build

Clone the repository and download dependencies:

```bash
git clone https://github.com/beedawn/surgepress.git
cd surgepress
go mod download
```

Build the CLI:

```bash
go build -o surgepress ./cmd
```

## Usage

SurgePress expects two arguments:

1. A directory containing Markdown files
2. A JSON configuration file

Run the compiled binary:

```bash
./surgepress <markdown-directory> <config.json>
```

Or run it directly with Go:

```bash
go run ./cmd <markdown-directory> <config.json>
```

Example:

```bash
go run ./cmd ./test_data ./test_data/configdata.json
```

## Configuration

The site configuration is JSON. A minimal example:

```json
{
  "Title": "My Blog",
  "Description": "A static site generated with SurgePress",
  "Link": "https://example.com",
  "Language": "en-US",
  "Global_Stylesheets": ["site.css"]
}
```

Supported configuration fields currently include:

- `Title` — site title
- `Description` — site description
- `Link` — base site URL
- `Language` — site language / RSS language
- `Global_Stylesheets` — stylesheets applied across generated pages

## Markdown Content

SurgePress parses Markdown and reads page metadata from front matter. Pages can provide metadata such as a title, date, template, and page-specific stylesheets.

Example:

```markdown
---
Title: Hello, World
Date: 2026-08-17
Template: default.html
Stylesheets:
  - post.css
---

# Hello, World

This page was generated by SurgePress.
```

If no template is specified, SurgePress falls back to `default.html`.

## Output

Generated site files are written under the `out/` directory. The generated output includes individual HTML pages and an `index.html`; the index build also triggers RSS generation.

Because `out/` is generated content, it should not be committed to source control.

## Development

Run the test suite:

```bash
go test ./...
```

Generate a coverage report locally:

```bash
go test ./... -coverprofile=coverage.out
go tool cover -html=coverage.out -o coverage.html
```

Coverage files are ignored by Git.

## Project Structure

```text
internal/
  argparser/            command-line argument parsing
  content/              page and rendered-page models
  filewalker/           Markdown file discovery
  filewriter/           generated-file output
  help/                 CLI usage/help
  indexpost/            index post model
  pagebuilder/          Markdown rendering and page/index generation
  pathutil/             filesystem/path validation helpers
  rssbuilder/           RSS feed generation
  siteconfig/           site configuration model
  template/             HTML templates
test_data/              sample/test content and configuration
```
