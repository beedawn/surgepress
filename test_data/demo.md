# Hello from SurgePress

This page started as a **Markdown** file and was turned into *HTML* by a static site generator written in Go.

## What it handles

- Front matter for title, date, template, and stylesheets
- Global and per-page CSS
- An auto-generated index page and RSS feed

## Try it yourself

    ./surgepress ./content config.json

Check out the source on [GitHub](https://github.com/beedawn/surgepress).
